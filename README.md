# L1 LzT Motors V3

Premium automotive marketplace for the IT session.

### Features
- Responsive navbar with mobile menu
- Home / Inventory / About / Contact routes
- Contact route has distinct gold highlight
- Dark / Light mode
- UZ / RU / EN switcher
- 60+ JSON vehicle records
- Load-more inventory
- Garage, vehicle details and dedicated `/buy/[id]` purchase route
- Admin dashboard via Ctrl + Alt + B
- Add / Edit / Delete inventory
- Analytics and search/filter
- Scroll reveal + premium automotive visuals

### Run
```bash
npm install
npm run dev
```
