# L1 LzT Motors

Premium automotive internet-store project for a technical college IT session.

## Run
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Features
- Next.js 15 + React
- Premium black/gold automotive UI
- Search, brand filter, sorting
- Product details modal
- Garage/cart
- Admin dashboard
- CRUD: add/edit/delete vehicles
- Admin shortcut: Ctrl + Alt + B
- Scroll reveal animations
- Responsive design

## Note
This is a frontend-only version as requested. Data is kept in React state, so it resets on page refresh.
